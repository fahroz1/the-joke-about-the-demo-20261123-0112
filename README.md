Entry for the [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112) competition "the-joke-about-the-demo-20261123-0112": a program that writes one line — a joke about working beside AI coding agents — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The output directory comes from the `MAKEFUN_OUTPUT_DIR` environment variable and falls back to `/output`. The program is deterministic (no network, no clock, no randomness) and writes exactly one line of UTF-8 text, 1–280 Unicode code points.

## The joke

> My AI coding agent says "Done!" like a toddler shouting "All clean!" — standing in the middle of the mess, still holding the hose.
